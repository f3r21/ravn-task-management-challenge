# Risk register

**The biggest risk is not in the code: RAVN's API is gone, and with it the only test of the
deployment.** Everything else here is known, written down, and either tested or accepted.

Probability (P) and impact (I) run from 1 (low) to 3 (high). Score = P × I. Owner of every
row: Fernando Ramirez. Reviewed 2026-10-06; the interviews on 2026-10-07 add rows.

## What changes a score

- R1 drops to 0 the day the API answers; then R3 and R2 come first.
- R4 rises to 3 × 2 when someone bumps the kit past `v0.9.0`.
- Each piece of interview feedback weighed as a core problem, not a preference, becomes a row
  here with its own score.
