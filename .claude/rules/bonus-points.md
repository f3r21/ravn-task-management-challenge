# RAVN Challenge Bonus Points

If requested to work on bonus features, adhere strictly to these 5 defined goals. Do not invent out-of-scope features.

1. **Drag and Drop:** Move tasks from one column to another and update their status. (Note: every hook needed for DnD is already installed).
2. **Task Counts:** Show the total count of tasks per column on the dashboard.
3. **List Layout:** Change the layout from columns to a list view.
4. **Date Delay Colors:** Change the text color of the due date based on delay:
   - **Green:** On time.
   - **Yellow:** Less than 2 days left.
   - **Red:** Date is older than the current date.
5. **Animations:** Add animations for when a new task is added to the board.
