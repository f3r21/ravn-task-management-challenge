# Task Management Challenge

A task management dashboard built for the RAVN frontend code challenge: browse tasks on a
status board, create them, edit them, delete them, and filter them, against RAVN's GraphQL
API.

Built as the week-4 capstone of the RAVN frontend Nerdery program.

> **Status:** in progress. Setup and running instructions, screenshots, and the full
> decision rationale land here as the phases complete.

## Setup

```bash
npm install
npm run dev
```
